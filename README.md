# RAG Pipeline – AI Document Question Answering

## Overview
This project demonstrates a Retrieval-Augmented Generation (RAG)
pipeline using Python and LangChain.

The pipeline loads documents, splits their content into chunks,
and prepares them for retrieval and question answering.

## Technologies Used
- Python
- LangChain
- PyPDF
- Sentence Transformers
- Text Splitting
- Document Loaders

## Key Features
- Load and process text documents
- Extract text from PDF documents
- Split documents into smaller chunks
- Prepare documents for semantic search
- Build the foundation for a RAG application

## Project Structure
- RAG_Pipeline.ipynb – Main project notebook

## How to Run
1. Clone or download this repository.
2. Install the required Python libraries.
3. Open the notebook in JupyterLab.
4. Run the cells in sequence.
